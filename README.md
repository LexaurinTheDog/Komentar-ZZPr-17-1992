# Komentář k zákonu č. 17/1992 Sb., o životním prostředí

Otevřený komentář k zákonu o životním prostředí — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; základní pojmy, trvale udržitelný rozvoj, zásada předběžné opatrnosti, povinnosti, ekologická újma, nástroje ochrany životního prostředí.

Konsolidované znění: dokument e-Sbírky `SB-1992-00017_2017-07-01`.
